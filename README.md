## SECTOR ABANDONADO (Android)

Shooter de supervivencia zombie por rondas en primera persona, low poly 3D, hecho con Godot 4.7.2 para Android (horizontal, pantalla completa).

| Descarga | Contenido |
|---|---|
| [`build/SectorAbandonado-debug.apk`](build/SectorAbandonado-debug.apk) | APK de prueba (debug, arm64-v8a) |
| [`build/SectorAbandonado-proyecto.zip`](build/SectorAbandonado-proyecto.zip) | Proyecto Godot completo, listo para abrir |
| [`game/`](game/) | Proyecto Godot (código, escenas, recursos) |
| [`tools/`](tools/) | Pipeline de recursos (retargeting, auto-rig, texturas, iconos, audio, balance) |
